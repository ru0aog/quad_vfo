# quad_vfo — библиотека квадратурного гетеродина для RP2040

Автономная библиотека квадратурного гетеродина (quadrature LO / VFO) для Raspberry Pi Pico / RP2040. Генерирует на двух соседних GPIO два меандра одной частоты со сдвигом фазы 90° (I/Q) — для питания SDR-смесителей (Tayloe, QSD/QSE, фазовых детекторов).

## Как это работает

### Формирование квадратуры

**PIO:** четырёхтактная программа, один state machine (SM), два соседних вывода GPIO.

Фазовая последовательность:

| Сигнал | Последовательность |
|---|---|
| I | `1, 1, 0, 0` |
| Q | `0, 1, 1, 0` |

Сигнал Q отстаёт от I на 90°. Чтобы изменить знак квадратуры, поменяйте выводы I и Q местами.

### Формирование частоты

Частота гетеродина определяется формулой:

\[
f_{LO} = \frac{f_{clk\_sys}}{4 \cdot div}
\]

где `div` — делитель PIO state machine в формате Q8.

### Выбор параметров PLL и делителя

При запуске сканер перебирает профили PLL (`refdiv`, `fbdiv`, `p1`, `p2`) и значения делителя PIO.

Цель — минимизировать взвешенную сумму штрафов за:

- отклонение `clk_sys` от предпочтительных значений;
- дробный делитель;
- неудачное значение `f_nco`;
- попадание в запрещённую частотную зону.

Если идеального варианта нет, сканер выбирает наименее неблагоприятный из допустимых кандидатов.

### Настройка системной частоты

Библиотека самостоятельно настраивает PLL. Это позволяет избежать бесконечного ожидания `LOCK`, которое возможно при использовании штатного `pll_init()` из SDK в случае неудачного захвата.

Успешная настройка подтверждается аппаратным флагом `LOCK` и измерением частоты с помощью счётчика FC0. Измеренная частота должна укладываться в допуск **±0,3%**.

Генератор запускается только после подтверждения системной частоты.

## Режимы работы

| Режим | Условие | Поведение |
|---|---|---|
| **Приёмник с ПЧ** | `if_shift_hz > 0` и `nco_max_hz > 0` | `LO = freq − if_shift`. Частота `f_nco` должна находиться в допустимом диапазоне: выше нуля, ниже `nco_max_hz` и вне запрещённой зоны. Сканер отдаёт предпочтение sweet-зоне. |
| **Точная частота** | `nco_max_hz == 0` | `LO = freq`. Ограничения NCO отключены, а делитель выбирается с минимальной ошибкой. Допуск связан с половиной шага между соседними значениями делителя Q8. |

Структура библиотеки:


## API

### Конфигурация

```cpp
typedef struct {
    PIO     pio;                 // pio0 / pio1
    int     sm;                  // 0..3 или -1 для автовыбора
    uint8_t pin_i;               // I = pin_i, Q = pin_i + 1; пины смежные

    quad_vfo_pll_t pll_nominal;  // Номинальная шина и профиль отката
    quad_vfo_pll_t pll_ceiling;  // Потолочный профиль при разгоне

    uint64_t xosc_hz;             // Опорная частота, обычно 12 МГц
    uint64_t clk_sys_min_hz;      // Нижняя граница окна сканера
    uint64_t clk_sys_max_hz;      // Верхняя граница clk_sys
    uint64_t pll_vco_max_hz;      // Пользовательский потолок VCO
                                  // Может превышать паспортные 1600 МГц.
                                  // Риск незахвата в таком случае — на пользователе.

    uint64_t clk_sys_nominal_hz;  // Граница overclock, обычно 133 МГц

    uint32_t if_shift_hz;         // LO = freq - if_shift
    uint32_t nco_max_hz;          // Максимум |f_nco|; 0 = точная частота

    uint32_t nco_sweet_lo;
    uint32_t nco_sweet_hi;

    uint32_t nco_forbid_lo;
    uint32_t nco_forbid_hi;
} quad_vfo_cfg_t;
```

Профиль `quad_vfo_pll_t` содержит параметры:

- `fbdiv` — множитель обратной связи, 16…320;
- `p1`, `p2` — выходные делители PLL;
- `clk_sys_hz` — целевая частота системной шины;
- `vsel` — уровень напряжения ядра;
- `is_oc` — признак разгона;
- `refdiv` — делитель опорной частоты.

Ограничения допустимых значений определяются реализацией PLL в библиотеке.

### Основные функции

```cpp
void quad_vfo_default_cfg(quad_vfo_cfg_t *cfg);
```

Заполняет конфигурацию значениями по умолчанию:

- PIO: `pio1`;
- SM: автоматический выбор (`sm = -1`);
- начальный GPIO: `pin_i = 0`;
- XOSC: 12 МГц;
- окно сканирования: 240…420 МГц;
- ПЧ: 11 000 Гц;
- частотные зоны: `9600…14500`, `0…5000`, максимум `62500` Гц.

```cpp
bool quad_vfo_init(const quad_vfo_cfg_t *cfg);
bool quad_vfo_init_simple(PIO pio, uint8_t pin_i);
```

Функции инициализации транзакционные: сначала проверяются параметры и захватываются необходимые ресурсы, затем освобождаются прежние.

Если функция возвращает `false`, прежняя конфигурация сохраняется.

```cpp
bool quad_vfo_start(uint32_t freq_hz);
void quad_vfo_stop(void);
```

`quad_vfo_start()` запускает генератор на заданной частоте.

Возможные причины отказа:

- `freq_hz <= if_shift_hz` — ранний отказ, генератор не затрагивается;
- требуемая частота LO превышает 45 МГц;
- сканер не нашёл допустимого кандидата — генератор не затрагивается;
- системная частота не подтверждена или не удалось подобрать делитель — генератор останавливается.

```cpp
uint32_t quad_vfo_actual_hz(void);
int32_t  quad_vfo_error_hz(void);
bool     quad_vfo_active(void);
void     quad_vfo_debug(void);
```

| Функция | Назначение |
|---|---|
| `quad_vfo_actual_hz()` | Расчётная фактическая частота LO; `0`, если генератор не запущен |
| `quad_vfo_error_hz()` | Ошибка частоты: `> 0` — LO ниже цели, `< 0` — выше |
| `quad_vfo_active()` | Возвращает состояние генератора |
| `quad_vfo_debug()` | Выводит параметры `clk_sys`, PIO, SM, делителя, PLL и LO |

### Информация о PLL

Функции ниже возвращают профиль PLL, применённый при последнем успешном запуске:

```cpp
uint16_t quad_vfo_pll_refdiv(void);
uint16_t quad_vfo_pll_fbdiv(void);
uint8_t  quad_vfo_pll_p1(void);
uint8_t  quad_vfo_pll_p2(void);

bool     quad_vfo_pll_nominal(void);
uint64_t quad_vfo_pll_vco_hz(void);
```

`quad_vfo_pll_nominal()` возвращает `true`, если генератор работает на номинальном профиле после отката.

`quad_vfo_pll_vco_hz()` рассчитывает частоту VCO по параметрам PLL. До запуска возвращает `0`.

### Управление диагностическим выводом

```cpp
void quad_vfo_set_quiet(bool on);
```

При `on == true` подавляет сообщения `[QUAD]` и `[PLL]`. Удобно при частой перестройке энкодером. Коды возврата функций не меняются.

### Низкоуровневый API PLL

Заголовок `quad_vfo_pll.h` предоставляет:

```cpp
uint32_t quad_vfo_vsel_for(uint64_t clk_hz);

uint32_t quad_vfo_clk_sys_hz(void);
uint32_t quad_vfo_clk_sys_meas_hz(void);

void quad_vfo_pll_set_quiet(bool on);
bool quad_vfo_set_clk_sys(...);
```

- `quad_vfo_clk_sys_hz()` — последняя подтверждённая частота системной шины.
- `quad_vfo_clk_sys_meas_hz()` — измерение FC0 с разрешением порядка 1 кГц.
- `quad_vfo_set_clk_sys()` — низкоуровневая настройка PLL; подробности см. в `quad_vfo_pll.h`.

## Пределы и особенности

### Максимальная частота LO

Верхний программный предел — **45 МГц** (`QUAD_VFO_LO_MAX_HZ`).

Выше примерно 45–50 МГц фронты GPIO становятся менее крутыми, а меандр превращается в сигнал с меньшей амплитудой и более синусоидальной формой. Это ухудшает качество квадратуры.

Надёжную квадратуру следует рассчитывать примерно до 30 МГц; 45 МГц — верхний программный предел, а не гарантия качества сигнала.

Проверка выполняется по `lo_hz`, уже с учётом вычитания `if_shift`. При превышении лимита функция завершается до изменения работающего генератора.

### Диапазон делителя PIO

Максимальное значение делителя SM в формате Q8 — `0xFFFF.FF`.

Минимальная частота LO приблизительно равна:

\[
f_{LO,\min} \approx \frac{f_{clk\_sys}}{4 \cdot 65535}
\]

При `clk_sys` около 240 МГц это соответствует частоте порядка единиц килогерц.

### Разгон и восстановление PLL

Параметры `clk_sys_max_hz` и `pll_vco_max_hz` задаются пользователем.

Захват PLL при выходе VCO за пределы паспортного диапазона не гарантирован. При неудаче библиотека пытается вернуться к `pll_nominal` и пересчитать делитель под фактическую системную частоту.

- **Номинальная частота подтверждена:** генератор может продолжить работу на номинальном профиле; в диагностике указывается `(nominal)`.
- **Номинальная частота не подтверждена:** библиотека переходит к безопасной остановке генератора.

### Ограничения NCO в режиме ПЧ

В режиме ПЧ:

\[
f_{NCO} = freq - LO_{\text{actual}}
\]

Частота NCO должна быть больше нуля, меньше `nco_max_hz` и находиться вне запрещённой зоны. Сканер предпочитает значения в sweet-зоне.

### Требования к GPIO

Выводы `pin_i` и `pin_i + 1` должны быть соседними.

На стандартной Raspberry Pi Pico GP28/GP29 связаны с VBUS-sense и ADC3. Для более чистого сигнала предпочтительнее использовать другие пары GPIO, например GP4/GP5.

### Точность измерения частоты

`quad_vfo_actual_hz()` и `quad_vfo_error_hz()` возвращают расчётные оценки, основанные на подтверждённой частоте `clk_sys`. Это не лабораторное измерение выходного сигнала.

`quad_vfo_clk_sys_meas_hz()` использует счётчик FC0 и имеет квантование порядка 1 кГц. Разница измерений на 1–2 кГц сама по себе не является признаком неисправности.

Точность LO также зависит от точности опорного генератора XOSC. При погрешности кварца ±30…50 ppm такую же относительную погрешность следует ожидать и у LO. Измерение `clk_sys` относительно того же XOSC не позволяет обнаружить уход самой опоры. Для работы в эфире требуется отдельная калибровка.

### Потокобезопасность

Библиотека не является потокобезопасной. Вызывайте API из одного контекста.

При переключении PLL прерывания на короткое время отключаются.

## Пример: энкодер и кнопка

Файл `quad_vfo_demo_encoder.ino` демонстрирует работу с энкодером по схеме, использованной в `RP2040_beacon`.

### Подключение

| GPIO | Назначение |
|---|---|
| GP20 | `ENC_A` (`INPUT_PULLUP`) |
| GP21 | `ENC_B` (`INPUT_PULLUP`) |
| GP19 | `ENC_BTN`, кнопка между GPIO и GND |

### Обработка энкодера

ISR по каналам A/B накапливает `enc_pending_steps` с помощью квадратурной LUT. Функция `enc_poll()` преобразует тики в детенты: **4 тика на один щелчок**.

При ускорении учитывается скорость вращения. Используются коэффициенты `×10` при интервале менее 150 мс и `×2` при интервале менее 400 мс — логика, перенесённая из маяка.

Диапазон перестройки: **1…45 МГц**.

### Работа кнопки

Опрос кнопки выполняется с антидребезгом 30 мс.

Последовательность нажатий:

1. Включение генератора, шаг 100 Гц.
2. Шаг 1 кГц.
3. Шаг 10 кГц.
4. Выключение генератора.

Перестройка выполняется только при включённом генераторе.

На время последовательности `stop → start` включается `quad_vfo_set_quiet()`, поэтому в терминал выводится только одна строка вида `freq=… step=…`.

## Подготовка к работе в эфире

Библиотека формирует **меандры I/Q**, а не готовый аналоговый синусоидальный LO. Для использования требуется внешний смеситель и соответствующая фильтрация.

Спектр непосредственно на GPIO содержит гармоники. Форма сигнала и качество квадратуры зависят от частоты, нагрузки, разводки платы и внешнего буфера.

Перед использованием в эфире рекомендуется:

- проверить форму и амплитуду обоих выходов осциллографом;
- проверить фазовый сдвиг и баланс амплитуд I/Q;
- измерить частоту и уровень гармоник анализатором спектра;
- проверить переключение частоты и восстановление после отказа PLL;
- откалибровать частоту по внешнему эталону.

**Важно:** успешный захват PLL и измерение `clk_sys` подтверждают работу системного тактирования, но не гарантируют лабораторную точность LO или соответствие выходного спектра требованиям конкретного передатчика.
